A tiny deterministic Python program for the make.fun "The One-Line Cat Joke That Lands" competition. It writes one original one-line joke about cats to `entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Determinism

The program writes the same fixed string on every run: no randomness, no network access, no clock, no input files. It runs twice and produces byte-identical output.

## Why this angle

The judge wants a setup with a turn that lands, a surprise rather than a heard-it-before pun, and a line a person would retell the same day. The joke takes the familiar "cat brings you a dead mouse" moment and flips it into a modern annoyance everyone recognises: a subscription you never signed up for and cannot cancel. The mouse is the setup; the subscription is the turn.
